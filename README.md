# 广附社区 · 校园手帐

在线网站：https://verlaine262.github.io/YDGF/

2026-10-25 更新：以暖白、森林绿和原创校园主题矢量插画重做首页，加入能够直接使用的个人工具。

## 校园手帐功能

- **学习自习室**：25 / 50 分钟专注、5 分钟休息，暂停、重置、跨页面计时和今日专注统计。
- **学习待办**：添加、勾选、移除任务以及清理已完成任务。
- **个人日历**：月份切换、按日期查看和添加日程、未来计划、ICS 日历文件导出。日程时间按使用者本地时间解释。
- **资源书架**：添加 HTTP/HTTPS 书签、分类、搜索、删除，保留原稿的学校贴吧入口。
- **我的手帐**：创建、编辑、删除随手记。
- **全站查找**：Ctrl / Command + K 查找页面功能和原稿社区内容。
- **显示与浏览**：浅色 / 深色 / 跟随系统，图片弹窗、键盘关闭弹窗、回到顶部、手机适配和减少动态效果支持。
- **个人数据备份**：导出 JSON，导入合并；同编号条目不重复，原有记录保留。社区收藏一并导出。

所有个人工具的数据仅存于当前浏览器，没有上传到 GitHub 或云端，也没有跨设备自动同步。清理浏览器数据前应导出备份。不同设备、浏览器和站点地址各自保存数据。主题插画为创作插画，并非学校实景。

## 维护

无需安装依赖。主页面为 index.html；assets/app.js 保留原站内容视图，assets/studio.js 提供校园手帐功能，assets/studio.css 提供新版视觉。originals 目录保持原稿内容。不要运行早期开发目录中的 build.cjs 覆盖新版页面。

推送到 main 会通过 .github/workflows/pages.yml 自动部署。GitHub Pages 的发布源需设为 GitHub Actions。

无需构建的静态网站，支持 GitHub Pages 子目录部署。打开 index.html 即可预览。

## 内容保留
原始 HTML、CSS、图片逐文件保存在 originals，SHA-256 校验见 preservation-manifest.json。所有 ASPX 页面转为 HTML 展示存档；完整源目录另有本地备份。原项目后端、数据库配置、编译产物不放入公开网站。社区动态按原始版本保留，原占位文字、示例日期与计数未冒充真实数据。

## 功能
首页、完整学校简介、社区全文搜索与本机收藏、学习和网盘入口、全部版本存档。登录注册不连接后端，不收集密码；网盘原稿没有下载地址。

## 发布
推送到 main 后自动运行 Pages 工作流。仓库 Settings → Pages → Source 选择 GitHub Actions。若首次自动启用失败，在设置启用 Pages 后重新运行工作流。

## 限制
点赞、发帖、登录、注册和文件上传需要另行接入后端。收藏仅保存在当前浏览器。学校简介为原稿历史资料。
