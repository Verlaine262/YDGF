# 广附社区 · YDGF

一个保留校园原稿、照片与回忆的静态社区网站，提供校园专题、学习工具及本机社区互动。

[访问网站](https://verlaine262.github.io/YDGF/) · [进入社区](https://verlaine262.github.io/YDGF/#community) · [技术支持](https://verlaine262.github.io/YDGF/#support)

## 当前状态

更新日期：2026-11-02。网站通过 GitHub Pages 发布，无需安装前端依赖或构建。

**个人发帖、回复、点赞及学习数据保存在当前浏览器，不会自动公开或跨设备同步。聊天与通话是明确标注的演示功能。** 登录入口尚未接入真实账号后端。

## 本地运行

在仓库根目录（包含 index.html 的目录）运行：

```sh
python -m http.server 8000
```

浏览器打开 http://localhost:8000/ 。建议使用本地 HTTP 服务检查资源加载与路由。无需 npm install。哈希路由支持 GitHub Pages 的 /YDGF/ 子路径。

## 内容保留与数据

原始文件位于 originals/，逐文件校验依据 preservation-manifest.json。现有校验记录包含 106 个保留文件和 11 篇原帖。原稿日期、计数及学校简介属于历史资料，不代表当前实时信息。

官方课表源文件为 data/official-GDPU2.json；“官方”指站长指定的固定课表。个人课程可编辑，官方课程不提供删除或修改入口。

个人数据应通过站内备份功能导出。独立保存的草稿、阅读记录及新增社区偏好不应假定全部包含在统一备份中，详见社区文档。清理浏览器站点数据可能导致本机内容丢失。

## 晚自习之后 · 视觉小说

入口：顶部「视觉小说」或 #galgame，也可直接打开 game/index.html。使用站长提供的双人插画，人物暂称阿澈与阿言，剧情为虚构校园故事。包含三处分支选择、三种结局、逐字显示、自动播放、对话回看、手动存档与自动续玩。游戏进度保存在当前浏览器的 gf-vn-auto、gf-vn-slot、gf-vn-endings，不包含在站内统一数据备份中。无在线服务、配音或付费内容。
