# 广附社区 · YDGF

一个保留校园原稿、照片与回忆的静态社区网站，提供校园专题、学习工具及本机社区互动。

[访问网站](https://verlaine262.github.io/YDGF/) · [进入社区](https://verlaine262.github.io/YDGF/#community) · [技术支持](https://verlaine262.github.io/YDGF/#support)

## 当前状态

更新日期：2026-11-10。网站通过 GitHub Pages 发布，无需安装前端依赖或构建。

**个人发帖、回复、点赞及学习数据保存在当前浏览器，不会自动公开或跨设备同步。聊天与通话是明确标注的演示功能。** 登录入口尚未接入真实账号后端。

## 本地运行

在仓库根目录（包含 index.html 的目录）运行：

```sh
python -m http.server 8000
```

浏览器打开 http://localhost:8000/ 。建议使用本地 HTTP 服务检查资源加载与路由。无需 npm install。哈希路由支持 GitHub Pages 的 /YDGF/ 子路径。

## 内容保留与数据

历史文件位于 originals/。站长已明确要求删除部分帖子、替换或移除部分图片，因此不再承诺全部原始文件字节不变。preservation-manifest.json 是早期保留记录，部分已替换文件的哈希仍属于历史版本，不能用作当前站点完整性校验。学校简介属于历史资料。

GDPU2 官方课表模块、脚本、样式和数据文件已删除。个人课程表入口与编辑功能保留；既有个人课程通过一次性迁移清空，之后可自行新增。

当前公开社区仅保留站务指南，原始帖子列表已清空；旧社区存档入口转到当前社区。现有本机帖子、评论、标记及草稿通过一次性迁移清理，之后仍可创建新的本机帖子。

个人数据应通过站内备份功能导出。独立保存的草稿、阅读记录及新增社区偏好不应假定全部包含在统一备份中，详见社区文档。清理浏览器站点数据可能导致本机内容丢失。

## 晚自习之后 · 视觉小说

入口：顶部「视觉小说」或 #galgame，也可直接打开 game/index.html。使用站长提供的双人插画，人物名为东哥与西坤，剧情为虚构校园故事。包含三处分支选择、三种结局、逐字显示、自动播放、对话回看、手动存档与自动续玩。游戏进度保存在当前浏览器的 gf-vn-auto、gf-vn-slot、gf-vn-endings，不包含在站内统一数据备份中。无在线服务、配音或付费内容。

## 代码工作区

入口 #code，独立页面 code/index.html。参考 GitHub 仓库界面，实现本机文件创建、编辑、重命名、删除、搜索、JSON 导入导出、最多 10 个项目快照和静态 HTML 预览。预览隔离运行，禁止脚本和外部网络，CSS 请内联。数据使用 gf-code-workspace-v1，不自动提交 GitHub，不纳入站内其他模块备份。

## 视频浏览

入口 #videos，独立页面 videos/index.html。YouTube 风格搜索、分类和卡片布局，支持原生视频播放、稍后观看、直链观看记录、列表连播、添加 HTTPS 视频直链与打开本机视频。内置一个明确标注的 W3Schools / Blender 动画示例，加载依赖外网。本站没有视频上传服务器；本机文件刷新后需重新选择，不计入持久观看历史。直链、收藏和历史保存于 gf-video-browser-v1，不自动纳入其他模块备份。普通平台页面地址不是可播放直链。
