workspace / 我的校园项目本机

从一个文件开始，把想法变成作品。

⑂ local

文件自动保存到当前浏览器，不会推送到 GitHub。

预览 index.html；样式和脚本请内联。外部网络与脚本执行已关闭。
本机项目快照
最多保留 10 个快照；恢复前会确认。不是 Git 提交。
让代码有自己的空间
创建与编辑文本文件，按 Tab 插入两个空格，Ctrl / Command + S 立即保存。文件列表支持按文件名或正文搜索。
导出项目会下载 JSON，包含文件和快照。导入会替换当前工作区，请先导出备份。每个文件最多 200 KB，项目最多 50 个文件。
这是本机编辑器，没有终端、真实 Git 分支、账号同步或云端运行环境。预览用于静态 HTML / CSS，不执行 JavaScript。
GitHub 风格布局为独立实现；与 GitHub 无隶属关系。
