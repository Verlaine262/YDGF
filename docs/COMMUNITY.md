# 社区功能说明

更新日期：2026-11-10。

## 功能范围

| 功能 | 当前行为 |
| --- | --- |
| 首页与探索 | 浏览公开站务指南及用户后来创建的本机帖子，支持搜索、频道与阅读筛选 |
| 通知 | 固定站务更新通知，可保存本机已读状态；不是实时推送 |
| 关注 | 保存主题关注偏好；不是跨账号关注关系，也不自动改变信息流 |
| 聊天 | 本次页面内发送文字、预设脚本回复、清空消息；没有真人收件人 |
| 通话 | 模拟呼叫、接通计时、静音状态和挂断；不连接真人，不启用麦克风或摄像头 |
| 历史记录 | 查看当前浏览器打开过的帖子 |
| 创作者中心 | 打开本机发帖编辑器，查看最近草稿标题 |
| 高级体验 | 免费设置与学习入口；没有订阅或付费系统 |
| 个人资料 | 保存独立的本机昵称；不会修改登录账号或自动替换既有帖子作者 |
| 更多 | 技术支持、关于网站、原版存档和学习工作台 |

聊天消息在重新打开聊天面板后重置；脚本回复不是 AI 在线服务。演示通话的静音仅改变界面状态。

## 发帖、编辑和删除

1. 点击发布，填写显示名称、频道、标题与正文。
2. 保存后帖子仅存在当前浏览器。新帖草稿自动保存；编辑已有帖子需主动保存。
3. 打开自己的本机帖子详情，可编辑、导出或删除。
4. 删除前会确认；确认后删除该本机帖子、关联本机回复、点赞与收藏，并清除对应阅读记录和回复草稿。当前没有回收站。

固定站务指南没有删除入口。旧原始帖子已由站长统一清空，旧社区存档转至新版社区。用户自行删除本机帖子的操作不会删除其他浏览器的数据。

## 站务认证

站务指南的头像右下角显示蓝色认证标志。认证依据内置站务帖子类型，不根据显示名称判断；普通用户把昵称改成“站务”不会获得认证。标志表示本站站务内容，不是第三方平台身份认证。

## 数据保存

- 本机帖子、评论、互动记录：使用既有个人数据状态及统一备份机制。
- 新帖草稿：aweb-community-draft。
- 阅读历史与回复草稿：aweb-community-reading。
- 通知已读：gf-notice-read。
- 关注偏好：gf-following。
- 独立个人昵称：gf-profile。
- 早期聊天草稿可能仍保留于 gf-message-draft；当前演示聊天不读取它。

独立存储项不保证进入统一导出文件。备份后请检查实际导出内容；不要把“已保存到本机”理解为服务器备份。不同站点地址、浏览器和设备的存储彼此独立。

## 后续接入边界

公开多人发帖、真实私信、实时通知、跨设备账号与语音通话仍需要服务端支持。当前演示入口不应被描述为已经上线的实时社交服务。

## 2026-11-10 清理迁移

新版首次加载会清空旧本机帖子、评论、点赞与收藏，移除新帖草稿和阅读/回复草稿。完成后写入 aweb-staff-only-cleanup，避免每次访问都重复清空。个人课程及较早的指定内容清理使用 aweb-content-cleanup-20261110。浏览器存储失败时，迁移可能未能持久化。

“仅保留站务”描述当前公开初始内容，不是关闭本机创作；迁移后新增或主动从备份导入的个人帖子仍可显示。
